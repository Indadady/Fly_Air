# Fly_Air

플라이유니티 항공발권처용 **항공 문서 통합 제너레이터**입니다.

GitHub Pages: https://indadady.github.io/Fly_Air/

## 문서 종류 (상단 메뉴)

| 메뉴 | 용도 |
|------|------|
| **1. 항공데포짓공문** | 거래처 대상 DEPOSIT INVOICE |
| **2. 환불영수증** | 학교·기관 제출용 취소 수수료 증명서 |
| **3. 환불내역서(내부)** | 내부/고객 안내용 환불 금액 내역서 |
| **4. 항공운임증명서** | [Airfare](https://indadady.github.io/Airfare/) 기반 플라이유니티 운임 증명서 |

## 주요 기능

- 실시간 A4 미리보기 · PDF 저장 (인쇄)
- JSON 백업/불러오기
- 빠른 양식 프리셋
- 플라이유니티 로고·직인 일괄 적용

## 로컬 실행

`index.html`을 브라우저에서 열면 됩니다.

## 기존 프로젝트와의 관계

- **Airseat** — 데포짓 청구서 기반
- **Airfare** — 항공운임증명서 기반 (투어메이커 → 플라이유니티 브랜딩 전환)
