# Fly_Air

플라이유니티 항공발권처용 **항공 문서 통합 제너레이터**입니다.

GitHub Pages로 배포하면 브라우저에서 바로 문서를 작성·인쇄(PDF 저장)할 수 있습니다.

## 문서 종류 (상단 메뉴)

| 메뉴 | 용도 |
|------|------|
| **1. 항공데포짓공문** | 거래처(여행사) 대상 DEPOSIT INVOICE |
| **2. 환불영수증(정식)** | 학교·기관 제출용 취소 수수료 증명서 (상세) |
| **3. 환불영수증(약식)** | 고객 안내용 약식 환불금 내역서 (금액 중심) |

## 주요 기능

- 실시간 A4 미리보기
- PDF 저장 (브라우저 인쇄 → PDF)
- JSON 백업/불러오기 (다른 이름 저장)
- 빠른 양식 프리셋 (사북고 대만 KE 샘플 포함)
- 수수료 항목 동적 추가/삭제 (정식 환불영수증)

## 로컬 실행

`index.html`을 브라우저에서 열면 됩니다.

## GitHub Pages 배포

1. GitHub에 `Fly_Air` 저장소 생성
2. 이 폴더 push
3. Settings → Pages → Source: `main` / `/ (root)`

배포 URL 예: `https://[username].github.io/Fly_Air/`

## 기존 Airseat와의 관계

기존 [Airseat](https://indadady.github.io/Airseat/) 프로젝트의 플라이유니티 데포짓 청구서를 기반으로,  
환불영수증 2종을 추가하고 플라이유니티 전용으로 재구성한 저장소입니다.
